# Руководство пользователя

## Требования

- Windows 10/11.
- Python 3.10 или новее с установленным компонентом Tcl/Tk.
- API-ключ OpenRouter с доступом к выбранным моделям.
- Подключение к интернету.

## Установка и запуск

Откройте PowerShell в папке проекта и выполните:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.pyw
```

При настроенной ассоциации файлов `.pyw` приложение можно запускать двойным щелчком. Расширение `.pyw` запускает Python GUI без отдельного консольного окна. Также можно использовать `pyw app.pyw` или `.venv\Scripts\pythonw.exe app.pyw`.

## Генерация изображения

1. Введите API-ключ в поле «API-ключ».
2. Нажмите «Загрузить модели» и выберите модель в выпадающем списке.
3. Введите описание изображения.
4. Чтобы развернуть описание в более подробный промпт, нажмите «Улучшить промпт». Этот шаг необязателен; результат можно отредактировать вручную.
5. Нажмите «Сгенерировать изображение». Результат появится в области предпросмотра.
6. Нажмите «Сохранить изображение», выберите папку и имя файла. Изображение сохраняется в исходном формате ответа.

Текстовая модель для улучшения задаётся в поле «Модель для улучшения промпта». По умолчанию используется `openai/gpt-4o-mini`; при необходимости укажите другую доступную текстовую модель. Переменные окружения `OPENROUTER_API_KEY` и `OPENROUTER_PROMPT_MODEL` могут задать начальные значения этих полей.

## Тесты

Установите зависимости и запустите:

```powershell
python -m pytest
```

Тесты проверяют фильтрацию моделей OpenRouter, обработку ответов генерации, улучшение описания и загрузку изображения по возвращённой URL. Для выполнения тестов API-ключ и сетевое подключение не нужны.

## Частые проблемы

- **Модели не загружаются:** проверьте API-ключ и подключение к интернету; список должен включать модели, у которых в OpenRouter заявлен вывод изображений.
- **Ошибка при улучшении описания:** проверьте название текстовой модели и наличие к ней доступа на аккаунте OpenRouter.
- **Модель завершила запрос без изображения:** выберите другую модель с поддержкой генерации изображений и повторите запрос.
- **Окно приложения не запускается:** проверьте, что в установленном Python есть Tcl/Tk. В Windows можно проверить запуск через `python app.pyw`, чтобы увидеть текст ошибки в PowerShell.
