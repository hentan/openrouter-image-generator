# OpenRouter Image Generator

Desktop-приложение на Python с графическим интерфейсом Tkinter для генерации изображений через OpenRouter. Оно загружает модели, поддерживающие вывод изображения, позволяет улучшить исходное описание с помощью текстовой модели и показывает полученную картинку.

## Запуск

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.pyw
```

В Windows также можно открыть `app.pyw` двойным щелчком, чтобы запустить приложение без окна консоли. Если ассоциация `.pyw` не настроена, запустите файл командой `pyw app.pyw` или `pythonw app.pyw`.

Введите API-ключ OpenRouter в окне приложения. Его можно заранее задать в переменной окружения `OPENROUTER_API_KEY`. Модель для улучшения промпта задаётся в `OPENROUTER_PROMPT_MODEL` (по умолчанию `openai/gpt-4o-mini`).

Выберите «Загрузить модели», затем модель изображения. Напишите описание и при необходимости нажмите «Улучшить промпт»: текст в поле заменится более подробным запросом, который можно отредактировать. Нажмите «Сгенерировать изображение», чтобы увидеть результат в блоке предпросмотра.

Подробное руководство и решение частых проблем доступны в [docs/USER_GUIDE.md](docs/USER_GUIDE.md).
